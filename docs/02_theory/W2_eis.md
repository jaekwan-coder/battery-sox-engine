> **주파수를 이용해서 확인하는 방법**이 있다. 이게 EIS다. M1과 완전히 같은
> 물리를 다른 도구로 다시 확인하는 것이라 생각하면 된다.

## M2.0. 교류와 임피던스 — 완전 기초부터

### 직류와 교류

**직류(DC)**: 전류·전압의 크기가 시간에 따라 안 변함 (건전지).
**교류(AC)**: 전류·전압이 사인파 모양으로 진동함 (콘센트 전기).

$$v(t) = V_0 \sin(\omega t)$$

$V_0$는 진폭, $\omega$는 각주파수($\omega=2\pi f$).

### 왜 교류를 배터리에 넣어보는가 — EIS의 발상

M1(시간 영역)에서는 전류를 계단 신호로 실험했다. EIS는 다르게, **아주
작은 진폭의 사인파 전류(또는 전압)를 셀에 넣고, 주파수를 아주 낮은
것부터 높은 것까지 바꿔가며 반응을 관찰**한다.

**왜 이렇게 하는가**: M1.5에서 봤듯 셀 안에는 빠른 현상(전해질 저항,
즉각적)과 느린 현상(확산, 수십 초)이 섞여 있다. **빠르게 흔드는 신호
(고주파)는 빠른 현상만 반응하고, 느리게 흔드는 신호(저주파)는 느린
현상까지 반응할 시간을 준다.** 주파수를 바꿔가며 재면 CT 촬영처럼 셀
내부의 여러 과정을 시간 스케일별로 분리해서 볼 수 있다.

### 저항에 교류를 넣으면

$$v(t) = i(t)\cdot R = I_0 R \sin(\omega t)$$

전압과 전류가 정확히 같은 타이밍에 오르내림(위상차 없음). 순간마다
$V=IR$이 그대로 성립.

### 커패시터에 교류를 넣으면 — 여기서 달라진다

$Q=CV$, $i=\frac{dQ}{dt}$를 이용하면 $v(t)=V_0\sin(\omega t)$일 때

$$i(t) = CV_0\omega\cos(\omega t)$$

**크기 관계**: $V_0 = \frac{I_0}{\omega C}$. "저항 역할을 하는 양"이
$\frac{1}{\omega C}$ — 주파수가 커질수록 작아짐(고주파에서 잘 통과,
저주파에서 크게 막음).

**타이밍(위상) 관계**: 전압은 $\sin$, 전류는 $\cos = \sin(\omega t+90°)$.
**전류가 전압보다 90도(1/4주기) 먼저** 움직인다.

### 복소수로 "크기 + 타이밍"을 한 번에

$$Z_R = R \quad(\text{실수, 위상차 없음}), \qquad Z_C = \frac{1}{j\omega C} \quad(\text{90도 위상 지연을 } j\text{로 압축})$$

**임피던스(impedance)**: 교류에서의 "저항"을 일반화한 개념. 크기와
위상을 동시에 담은 복소수.

$$Z(\omega) = \frac{V(\omega)}{I(\omega)}$$

> **W0과의 연결**: `W0_foundations.md` Q2에서 "$s=j\omega$를 대입하면
> 주파수 응답이 된다"고 한 것의 실체가 바로 이것. 라플라스 영역
> 임피던스 $Z(s)$에서 $s=j\omega$로 바꿔 넣으면 이 교류 임피던스가 나온다.

## M2.1. RC 병렬의 임피던스 — 직접 계산해서 반원 확인

### 병렬 임피던스 합성

$$\frac{1}{Z} = \frac{1}{R}+\frac{1}{Z_C} = \frac{1}{R}+j\omega C
\quad\Longrightarrow\quad Z(\omega)=\frac{R}{1+j\omega RC}$$

(`W0_foundations.md`의 $Z(s)=\frac{R}{1+sRC}$에 $s=j\omega$ 대입한 것과 동일)

### 실수부·허수부로 분리

켤레복소수를 분자·분모에 곱해 정리:

$$Z(\omega) = \underbrace{\frac{R}{1+(\omega RC)^2}}_{Z'} \; - \; j\underbrace{\frac{\omega R^2 C}{1+(\omega RC)^2}}_{Z''}$$

### 극한값 검산

- $\omega\to0$: $Z'\to R$, $Z''\to0$ (직류에 가까우면 그냥 저항 R)
- $\omega\to\infty$: $Z'\to0$, $Z''\to0$ (커패시터가 뚫린 통로처럼 작동)

### 나이퀴스트 선도 = (Z', -Z'') 점들의 자취

관례상 y축에 $-Z''$(부호 반전)을 쓴다.

| $\omega$ | $Z'$ | $-Z''$ |
|---|---|---|
| 0 | $R$ | 0 |
| $1/RC$ | $R/2$ | $R/2$ (반원 꼭대기) |
| $\to\infty$ | 0 | 0 |

수학적으로 $(Z'-R/2)^2+(Z'')^2=(R/2)^2$가 성립 — 중심 $(R/2,0)$, 반지름
$R/2$인 원의 위쪽 절반. **정확히 반원이 나온다.**

```
-Z''
 |      __
 |    /    \
 |   /      \
 |  /        \
 +-+----------+---- Z'
   0          R
  (w->inf)  (w->0)
```

**반원의 지름 = R(저항값)**, **반원 꼭대기의 주파수 = $1/RC=1/\tau$**.
반원 하나에서 R과 τ(따라서 C도) 를 동시에 읽어낼 수 있다.

## M2.2. RC 여러 개가 직렬로 연결되면 왜 반원이 여러 개인가

### 병렬과 직렬을 구분

**RC 블록 자체는 내부적으로 R과 C가 "병렬"**로 묶인 것이고, **그 블록
여러 개가 서로 "직렬"로 이어진 것**이다.

```
전체 회로 = R0 -- [R1||C1] -- [R2||C2] -- 단자
                  블록1(병렬)   블록2(병렬)
                       (블록끼리는 직렬)
```

직렬 연결은 저항처럼 그냥 더한다:

$$Z_{total}(\omega) = R_0 + Z_1(\omega) + Z_2(\omega), \qquad
Z_1=\frac{R_1}{1+j\omega R_1C_1},\;\; Z_2=\frac{R_2}{1+j\omega R_2C_2}$$

### 숫자로 직접 확인 — 시상수가 충분히 다를 때

**설정**: $R_0=0.01\Omega$, 블록1: $R_1=0.02\Omega, C_1=100F$
($\tau_1=2$s), 블록2: $R_2=0.05\Omega, C_2=2000F$ ($\tau_2=100$s).
τ1과 τ2가 50배 차이.

- **$\omega=10$ rad/s (빠름)**: $\omega R_1C_1=20$(큼) → $Z_1\approx0$.
  $\omega R_2C_2=1000$(더 큼) → $Z_2\approx0$. 둘 다 죽어있어 전체는
  $R_0$ 근처.
- **$\omega=0.5$ rad/s ($=1/\tau_1$, 블록1 반원 꼭대기)**: $Z_1=0.01-j0.01$
  (반원 진행 중). $Z_2\approx0$(아직 거의 안 반응). → **이 순간 전체
  임피던스는 거의 블록1만 반영.**
- **$\omega=0.01$ rad/s ($=1/\tau_2$, 블록2 반원 꼭대기)**: $Z_1\approx0.02$
  (이미 R1값으로 수렴 완료, 반원 다 그림). $Z_2=0.025-j0.025$(지금 한창
  반원 진행). → **블록1은 상수처럼 고정, 블록2가 새 반원을 그리는 중.**

### 왜 반원이 분리되어 보이는가

**핵심**: τ1과 τ2가 충분히 차이 나면, **블록1이 자기 반원을 다 그리고
완전히 끝난 뒤에야 블록2가 반원을 그리기 시작**한다.

```
고주파 ------------------------------------> 저주파
[블록1이 반원 그리는 구간]   [블록1은 끝, 블록2가 반원 그리는 구간]
     (tau1 근방)                  (tau2 근방, 훨씬 낮은 주파수)
```

전체 그림:

```
-Z''
 |      __                    ____
 |    /    \              /        \
 |   /      \__          /            \
 |  /           \_______/               \
 +-+------------+-----------------------+---- Z'
  R0          R0+R1                 R0+R1+R2
 (w 큼)      (w=1/tau1)             (w=1/tau2)
```

**첫 반원의 지름 = R1**, 그 반원이 끝나는 지점(x축 값)이 $R_0+R_1$이고,
거기서 **두 번째 반원이 다시 시작**해 지름 R2만큼 더 나아간다. 직렬
연결이니 두 반원이 옆으로 나란히 이어 붙은 모양이 된다.

### τ가 가까우면? — W0 Q2와의 연결

τ1=2초, τ2=3초처럼 **비슷하면**, 블록1이 아직 반원을 다 못 그렸는데
블록2가 벌써 시작해버려 **두 반원이 겹쳐 뭉개진 하나의 찌그러진 반원**
처럼 보인다. 이는 `W0_foundations.md` Q2의 "라플라스 극점이 가까우면
데이터로 구분이 안 된다"의 실제 모습. 이럴 때 억지로 2개 RC로 피팅하면
파라미터가 불안정해진다(`W3_parameter_identification.md`에서 다룸).

### 정리: 반원 개수의 규칙

**직렬로 이어진 RC 병렬 블록의 개수 = 나이퀴스트 선도에서 (원칙적으로)
보이는 반원의 개수**, 단 조건은 **각 블록의 시상수가 서로 충분히
떨어져 있어야** 한다.

### 실제 셀에서 반원이 여러 개인 이유

M1.5에서 "관문2 = 전극표면 전하이동 반응"이라 뭉뚱그렸는데, 실제로는
두 단계를 더 거친다.

1. **SEI 층 통과**: 음극 표면을 덮은 SEI 막을 리튬 이온이 통과. 막
   저항($R_{SEI}$)과 양쪽 전하축적 효과($C_{SEI}$) → **RC 블록 하나**
2. **전하이동 반응**: SEI 통과 후 전극 결정 표면에서의 실제 화학반응
   → 저항($R_{ct}$)과 전기이중층 커패시턴스($C_{dl}$) → **또 다른 RC 블록**

두 블록의 시상수가 보통 다르기(τ_SEI ≠ τ_ct) 때문에, 나이퀴스트 선도에
반원이 두 개로 나뉘어 나타난다.

## M2.3. 실제 EIS 실험은 무엇을 하는가

### 측정 절차

1. 셀을 특정 SOC, 특정 온도로 맞추고 충분히 안정시킴(평형 대기)
2. **아주 작은** 진폭의 사인파 전류(또는 전압)를 흘림 — 크게 흔들면
   셀이 비선형적으로 반응해(M1.5의 각 관문이 다르게 반응) 선형 회로
   이론이 안 맞게 됨
3. 그 주파수에서 실제 응답의 크기·위상차를 측정 → $Z(\omega)$ 한 점 획득
4. 주파수를 바꿔가며(보통 수 kHz ~ 수 mHz, 매우 넓은 범위) 반복
5. 얻은 점들을 나이퀴스트 평면에 전부 찍음

**왜 이렇게 넓은 주파수 범위를 쓰는가**: M1.5의 세 관문이 각각 다른
시간 스케일(즉각적/수초/수십초~분)을 가지므로, 다 잡아내려면 고주파
(빠른 현상용)부터 저주파(느린 현상용)까지 훑어야 한다.

### 실제 셀의 나이퀴스트 선도

```
-Z''
 |                    __
 |         ___      /    \
 |       /     \  /        \___
 |      /        \               \___/  (45도 -> 수직상승)
 +---+-+-----------+-------------------- Z'
    고주파        중간              저주파
  (인덕티브     (반원 1~2개:        (확산: Warburg,
   꼬리 있을수도) SEI, 전하이동)      그 후 수직상승)
```

## M2.4. Randles 회로 — 나이퀴스트 선도를 회로로 정리한다는 것의 의미

### 오해 바로잡기: 새로운 개념이 아니다

Randles 회로는 M1.5~M1.6에서 이미 만든 회로 — $R_0$ + $(R_1\|C_1)$ +
확산 항 — 에 전기화학 분야가 붙인 이름이다. 1947년 B. A. Randles가
전극 반응을 이 구조로 처음 모델링해 이름이 붙었다. **우리가 이미
유도한 것에 뒤늦게 이름표를 붙인 것**이지, 새로 유도한 게 아니다.

### "나이퀴스트 선도를 회로로 정리한다"의 정확한 의미 — 방향의 구분

**방향 A (M2.1에서 한 것, 정방향)**: "회로를 먼저 가정하고(R0+RC1+RC2),
그 회로가 만드는 나이퀴스트 곡선을 계산으로 그려본다." 회로 → 곡선.

**방향 B (실제 실험, 역방향)**: "실험으로 나이퀴스트 곡선(데이터
점들)을 얻었다. 이 곡선 모양을 보고 어떤 회로였길래 이런 모양이
나왔을지 거꾸로 추리한다." 곡선 → 회로.

**Randles 회로는 방향 B를 위한 표준 템플릿**이다. 실험가가 데이터를
얻었을 때 맨땅에서 회로를 상상하지 않고, "일단 이 표준 구조(R0 +
반원들 + Warburg)를 가정하고 데이터에 맞춰 숫자만 피팅해보자"는 출발점.

### 왜 이 구조가 표준 템플릿인가 — 패턴 인식표

| 곡선의 형태 | 회로 요소 |
|---|---|
| 고주파에서 실수축과 만나는 점 | 순수 저항 $R_0$ |
| 반원 | RC 병렬 |
| 45도 직선 → 저주파 수직 | Warburg (확산) |

이 대응 규칙 자체가 "패턴 인식표"다. 데이터를 보고 "고주파 쪽에
절편이 있으니 R0, 반원이 하나(또는 두 개)니 RC가 하나(또는 두 개),
저주파에 45도 선이 있으니 Warburg"라고 **곡선의 생김새로부터 회로
부품 구성을 역추적**한다. 배터리를 비롯한 대부분의 전기화학
시스템에서 이 결과가 거의 항상 "R0 + 반원 1~2개 + Warburg"로
귀결되기 때문에 업계 전체가 공유하는 표준 출발점이 되었다.

**비유**: 의사가 엑스레이 사진을 보고 그림자 모양으로 골절을
진단하듯, "뼈가 부러지면 엑스레이에 이런 그림자가 생긴다"는 알려진
대응관계(M2.1~M2.5)가 먼저 있고, 그걸 거꾸로 써서 그림자만 보고 뼈
상태를 추정하는 것. Randles 회로는 전기화학 시스템의 표준
엑스레이 판독 템플릿.

### 표준 구성 (회로도)

$$Z_{total}(\omega) = R_0 + \left(\frac{1}{R_1}+j\omega C_1\right)^{-1} + Z_{Warburg}(\omega)$$

```
     R0        R1
--WWW--+--WWW--+
       |       |
       +---||--+   (C1, 전기이중층)
               |
             Warburg(확산)
```

| 나이퀴스트 구간 | 회로 요소 | M1의 물리적 대응 |
|---|---|---|
| 고주파 실축 절편 | $R_0$ | 전해질/집전체 저항 (M1.5 관문1) |
| 첫 번째 반원 | $R_{SEI}\|C_{SEI}$ | SEI 층 통과 |
| 두 번째 반원 | $R_{ct}\|C_{dl}$ | 전극표면 전하이동 반응 (M1.5 관문2) |
| 저주파 45도 → 수직상승 | Warburg + 확산 커패시턴스 | 고체 내 확산 (M1.5 관문3) |

M1.5의 "관문 1/2/3"이, 실제로 재면 나이퀴스트 선도 위에서 "고주파
절편, 반원들, 저주파 곡선"으로 각각 눈에 보이는 도형이 된다. **같은
물리를 시간 영역(M1)과 주파수 영역(M2) 두 가지 방법으로 확인한 것.**

### 인덕티브 꼬리 (참고)

아주 높은 주파수(수 kHz 이상)에서는 배선·권취 구조의 **인덕턴스(L)**
성분이 나타날 수 있다. $Z_L=j\omega L$은 커패시터와 부호가 반대라
나이퀴스트에서 반원과 반대 방향(위쪽)으로 살짝 꺾이는 꼬리를 만든다.

## M2.5. 확산과 Warburg 임피던스 — 45도 선의 정체

### 왜 확산은 RC로 정확히 안 되는가

RC의 저항은 주파수와 무관하게 R이라는 고정값으로 수렴한다(M2.1).
그런데 확산은 다른 성격을 가진다. 확산 방정식을 풀면

$$Z_W(\omega) = \frac{\sigma}{\sqrt{\omega}}(1-j) = \frac{\sigma}{\sqrt{\omega}} - j\frac{\sigma}{\sqrt{\omega}}$$

($\sigma$는 Warburg 계수)

### 왜 45도 직선이 나오는가

실수부와 허수부의 **크기가 항상 똑같다**($\frac{\sigma}{\sqrt\omega}$로
동일). x좌표와 y좌표가 항상 같은 점들은 원점을 지나는 기울기 1의
직선, 즉 **45도 직선**을 그린다.

**직관**: 확산은 "얼마나 깊이까지 리튬이 파고들었는가"가 계속 늘어나는
과정이다. 주파수를 낮출수록(천천히 흔들수록) 리튬이 더 깊이 파고들
시간을 가지므로, "저항 같은 효과"와 "지연 효과"가 함께 계속 커진다.
RC처럼 특정 지름(반원)에서 멈추지 않고, **주파수가 낮아질수록 끝없이
더 커지는** 것이 확산의 특징이며, 이것이 반원이 아니라 계속 뻗어나가는
직선으로 나타나는 이유다.

### 왜 정수차 RC로는 완벽히 흉내 못 내는가

RC 하나는 나이퀴스트에서 특정 지름에서 멈추는 반원을 만든다. RC를
여러 개 겹쳐도 여러 반원이 이어진 모양이지, 끝없이 뻗어나가는 진짜
45도 직선을 정확히는 못 만든다. 아주 많이 겹치면 근사적으로 흉내
낼 수 있지만 이론적으로 정확히 같지는 않다. **분수차(fractional-order)
모델**이 이런 배경에서 존재한다($\sqrt\omega$ 같은 정수가 아닌 차수를
직접 다루는 수학).

### 유한 확산 — 저주파에서 다시 수직으로 서는 이유

이론적 Warburg는 확산이 무한히 깊은 공간에서 일어난다고 가정한다.
하지만 실제 전극 입자는 크기가 유한하다. **아주 낮은 주파수**로
가면 확산이 입자 전체에 다 퍼져버려 더 이상 "계속 뻗어나가는" 거동이
아니라 **한계에 도달한 거동**(유한한 저장 용량에 도달, 커패시터처럼)
으로 바뀐다. 나이퀴스트에서 45도 선이 끝나고 **거의 수직으로 서는
모양**으로 나타나며, 이를 **유한확산 Warburg**(또는 확산
커패시턴스)라 부른다.

**M1.5의 RC2와 연결**: M1.6에서 "관문3(확산)을 RC2 하나로 근사한다"고
한 것이, EIS 관점에서는 "Warburg의 저주파 수직상승 부분을 RC 하나로
뭉뚱그려 근사한 것"과 같은 이야기다. 정밀하게 하려면 Warburg를
그대로 쓰거나 유한확산 요소를 별도로 넣어야 하지만, ECM 수준에서는
RC 근사로 실용적으로 충분한 경우가 많다.

## M2.6. 나이퀴스트 vs 보데 선도 — 언제 무엇을 쓰는가

나이퀴스트가 유일한 표현 방법은 아니다. 같은 데이터 $Z(\omega)$를
다르게 그리는 방법으로 **보데 선도(Bode plot)**가 있다.

### 보데 선도란

가로축을 주파수(로그 스케일)로, 세로축에 임피던스 크기($|Z|$)와
위상각($\phi$)을 각각 별도 그래프 두 개로 그린다.

$$|Z(\omega)| = \sqrt{Z'^2+Z''^2}, \qquad \phi(\omega)=\arctan\left(\frac{-Z''}{Z'}\right)$$

```
|Z| (로그축)                    phi (위상각)
 |                                |
 |--\                             |      /-\
 |    \___                        |    /     \___
 |        \___                    |  /             \
 +--------------> w(로그축)       +--------------------> w(로그축)
```

### 각각의 강점과 약점

**나이퀴스트 강점**: 여러 RC(반원)를 한눈에 시각적으로 구분하기 좋다.
"반원이 몇 개인가, 서로 겹치는가"를 보는 첫 단계에 최적.

**나이퀴스트 약점**: **주파수 정보가 그래프 안에 안 보인다.** 점 하나가
몇 Hz인지 그림만으론 모름(보통 몇 점 옆에 숫자를 따로 적어줌). x축과
y축 스케일을 똑같이 맞춰야(정사각형 비율) 반원이 진짜 반원으로
보이는데, 자동 비율 조절 시 착시가 생길 수 있다.

**보데 강점**: 주파수가 축 자체이므로 "이 열화가 몇 Hz(몇 초
시상수)대에서 일어나는가"를 정확히 읽을 수 있다. 크기($|Z|$)만
보면 저항의 전체적 증감(열화 정도)을 한눈에 비교하기 좋다.

**보데 약점**: 반원이 여러 개 겹쳤을 때 나이퀴스트만큼 "몇 개의
RC로 이루어졌는지" 시각적으로 바로 안 보임. 그래프 두 개를 같이 봐야 함.

**실무에서는 둘을 같이 쓴다.** 나이퀴스트로 구조(몇 개의 RC인가)를
먼저 파악하고, 보데로 정확한 주파수 위치와 전체적인 크기 변화 추이를
확인한다. 논문·기업 보고서에서 나이퀴스트와 보데를 나란히 붙여
제시하는 것이 표준 관행이다.

### 그 외 방법 (참고)

- **Kramers-Kronig 검증**: 측정 데이터가 물리적으로 말이 되는지(측정
  오류, 셀 불안정성 등)를 검증하는 수학적 방법. EIS 데이터를 신뢰하기
  전 반드시 거치는 절차.

## M2.7. 이게 왜 필요하고, 실제 기업에서 어떻게 쓰이는가

### 왜 필요한가 — 근본 이유

배터리는 열어서 안을 볼 수 없다. 그런데 셀 내부에 뭐가 얼마나 있는지
(전해질 저항, SEI 두께, 확산 속도)를 알고 싶다. 단자에 전압계 하나
대는 것만으로는 이들을 구분할 방법이 없고, 전체 저항 하나만 나온다.
**주파수를 스캔하는 EIS만이 시간 스케일별로 내부 요소들을 분리해서
보여준다.** 이것이 EIS가 필요한 근본 이유다.

### 반원이 구분되면 얻는 것 — 실제 시나리오

반원 두 개가 깔끔히 분리되면, 각 반원의 지름·위치에서 각 과정의
저항값($R_{SEI}$, $R_{ct}$)을 독립적으로 뽑아낼 수 있다.

**시나리오: 셀이 노화됐다. 어디가 문제인가?**

새 셀과 노화된 셀의 EIS를 비교했을 때,

- **SEI 반원만 커졌다** → SEI 층이 계속 두꺼워지고 있다는 뜻(M1.5 관문2 관련
  열화) → **리튬 재고 손실(LLI)** 문제로 진단
- **전하이동 반원만 커졌다** → 전극 표면 활성 면적 감소 또는 표면 오염
  → **활물질 손실(LAM)** 쪽 문제로 진단
- **둘 다 커졌다** → 복합적 열화

**반원이 구분되면, 저항이 "얼마나" 커졌는지뿐 아니라 "왜" 커졌는지
(어느 메커니즘 때문인지)까지 알 수 있다.** 이것이 EIS의 진짜 가치이며,
단순 저항 측정으로는 절대 얻을 수 없는 진단 정보다. (LLI/LAM 상세
분류는 `W6_soh.md`에서 본격적으로 다룬다.)

### 반원이 안 구분되면 잃는 것

두 반원이 뭉개지면(시상수가 가까울 때), 전체 저항값은 여전히 잴 수
있지만 SEI 때문인지 전하이동 때문인지 나눌 수 없다. 진단 정보가
"저항이 커졌다"는 뭉뚱그린 결론으로 후퇴한다.

**DRT(Distribution of Relaxation Times, 참고)**: 겹친 반원을 억지로
분해하지 않고, "이 시스템이 얼마나 다양한 시상수를 가진 과정들의
연속적 혼합으로 이루어져 있는가"를 통계적으로 추정하는 심화 기법.
반원이 구분 안 될 때 연구자들이 동원하는 고급 도구.

### 순수 수학인가, 물리적으로 실재하는가 — 완전히 물리적으로 실재한다

$R_0$, $R_{SEI}$, $C_{SEI}$, $R_{ct}$, $C_{dl}$은 각각 실제 물리량과
정확히 대응된다.

- $R_0$: 전해질 이온 전도도, 배선·접촉 저항의 합. 다른 방법으로
  재도 비슷한 값이 나와야 함
- $C_{dl}$: 전극 표면적에 거의 비례. 실제로 전극 표면적 산정에 EIS를 사용
- $R_{ct}$: 반응속도상수와 직접 연결되어 실제 반응 속도를 역산 가능
- Warburg 계수 $\sigma$: 리튬의 고체 내 확산계수와 직접 연결되어,
  EIS 데이터로 확산계수를 실제로 계산할 수 있고 다른 방법으로 잰
  값과 비교 검증까지 이루어짐

**주의**: Randles 회로 자체는 실제 셀의 복잡한 다공성 전극 구조를
단순화한 근사 모델이라는 한계는 있다. 연구자들은 피팅한 파라미터를
너무 정밀한 절대값으로 해석하기보다, **상대적 비교**(새 셀 대비 노화
셀, A사 대비 B사 셀)에 주로 사용한다. "R_ct가 정확히 이 값이다"보다
"R_ct가 노화 전보다 3배 커졌다"는 비교가 훨씬 신뢰도 높은 결론이다.

### 실제 기업·연구소에서의 활용

| 부서/단계 | 용도 |
|---|---|
| 소재개발팀 | 신소재(전해질 첨가제, 음극 후보) 스크리닝. 완전한 수명시험 전
초기 EIS 특성으로 성능 예측, 유망 후보만 다음 단계로 |
| 생산/품질팀 | 코팅 불균일, 전해질 주입 불량 등 미세 결함을 R0·반원 이상으로
검출 (부분적, 전수검사보다 샘플링/R&D 위주) |
| R&D/신뢰성팀 | 다양한 조건(고온 보관, 급속충전 반복, 저온 사용)에서
노화시키며 주기적 EIS 측정 → 어느 조건에서 어떤 메커니즘(LLI/LAM)이
지배적인지 규명 → BMS 설계·사용 가이드라인에 반영 |
| BMS 알고리즘팀 | HPPC로 뽑은 ECM 파라미터를 EIS 결과와 교차검증.
크게 다르면 HPPC 피팅에 문제(예: 시상수 분리 실패) 신호로 해석 |
| 선행연구팀 | **온보드(on-board) EIS**: 차량 DC-DC 컨버터·인버터
스위칭을 이용해 특정 주파수 성분을 만들고 간이 임피던스를 실시간
추정하는 연구. 상용화되면 주행 중 실시간 정밀 SOH 진단이 가능해짐
(현재 연구·초기 상용화 단계, 배터리 업계 활발한 연구 주제) |

**"신규 소재 셀 특성 분석"이라는 SOX 직무 문구는 정확히 R&D/신뢰성팀과
BMS 알고리즘팀 접점에서, EIS 같은 도구로 소재를 분석하고 그 결과를
ECM·알고리즘에 반영하는 일을 가리킨다.**

## 노화와 열화 — 다시 확인

- **노화(aging)**: 시간에 따른 성능 저하 (현상, 결과)
- **열화(degradation)**: 그 저하를 일으키는 구체적 메커니즘 (원인,
  예: SEI 성장, LAM, LLI)

EIS는 정확히 "노화라는 결과를 관찰하고, 반원 분리를 통해 그 뒤에 숨은
열화 메커니즘(원인)을 진단"하는 도구다.
