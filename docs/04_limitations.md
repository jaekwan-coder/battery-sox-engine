# 이 구현의 한계

이 프로젝트가 무엇을 할 수 있고, 무엇을 할 수 없는지를 명시합니다.
**한계를 정확히 아는 것이 결과를 자랑하는 것보다 중요합니다.** 이 문서는
프로젝트가 진행되면서 계속 갱신됩니다.

## 모델 구조의 한계

- 본 구현은 등가회로모델(ECM) 기반이며, 셀 내부의 전기화학적 상태
  (음극 전위, 리튬 농도 분포 등)를 직접 표현하지 않는다. 단자 거동만을
  근사하므로 **급속충전 시 리튬 석출 한계 산정에는 적합하지 않다.**
  이 영역은 SPM/SPMe 등 축소 전기화학 모델이 필요하다 (`docs/02_theory/W1_electrochemistry_ecm.md` 참고,
  향후 작성).
- 2RC 모델은 대부분의 조건에서 유효하지만, 극저온이나 고율 충방전처럼
  비선형성이 강한 영역에서는 오차가 커질 수 있다. (검증 결과는 W4 완료 후 추가)

## 데이터 범위의 한계

- 파라미터 식별에 사용한 데이터는 [범위 명시 예정: 예) −20~40℃, LG
  18650HG2 셀]로 제한된다. 이 범위를 벗어난 조건(예: 다른 소재의 셀,
  더 극단적인 온도)에서의 정확도는 보장되지 않는다.
- LFP처럼 OCV가 평탄한 소재에 대해서는 별도 검증이 필요하다
  (`docs/02_theory/W0_foundations.md` Q4의 가관측성 소실 문제 참고).

## 검증의 한계

- (W4-5 완료 후 채울 항목) NIS/백색성 검정을 통과한 조건의 범위
- (W4-5 완료 후 채울 항목) 스트레스 테스트에서 발견된 실패 모드

## 실시간성/임베디드 관점의 한계

- 본 구현은 Python 기반이며, MCU에서의 고정소수점 연산·연산시간
  제약은 W8에서 부분적으로만 다룬다. 실제 양산 수준의 검증(HIL 등)은
  이 프로젝트의 범위 밖이다.

## 안전 인증 관점의 한계

- 본 프로젝트는 학습·포트폴리오 목적이며, ISO 26262 등 기능안전
  표준의 정식 인증 절차(추적성 문서화, MISRA-C 100% 준수 등)를
  따르지 않는다. W8에서 개념적 이해와 일부 실습만 다룬다.
