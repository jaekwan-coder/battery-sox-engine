# 결과 그림 저장소

이 폴더에는 각 모듈에서 생성한 그림(파라미터 표면, 나이퀴스트 선도,
NIS 검정 결과 등)과 그 해석을 저장합니다. 대용량 이미지 파일 자체는
`.gitignore`에 의해 추적되지 않으므로, 재현 가능하도록 생성 노트북/
스크립트 경로를 함께 기록하세요.

## 파일 명명 규칙

`w{주차}_{내용}.png` 형식. 예: `w3_r0_surface.png`, `w4_nis_ekf.png`
