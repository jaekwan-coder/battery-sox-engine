# 설계 결정 로그

이 프로젝트에서 내린 설계 결정과 그 근거를 기록합니다. **이 문서가 이 저장소에서
가장 중요한 파일입니다.** 코드는 완성된 결과만 보여주지만, 이 문서는 왜
그 결과에 도달했는지를 보여줍니다.

형식: 번호 / 날짜 / 맥락(무엇을 하다가 이 결정이 필요해졌나) / 고려한 대안(최소 2개) /
선택 / 근거 / 폐기한 실험의 보존 위치(있다면)

## D-001: ECM의 RC 개수를 2개로 결정

**날짜**: 2026-XX-XX
**맥락**: HPPC 완화 구간 데이터를 1RC로 피팅했더니, 펄스 종료 후 초반 5초는
잘 맞는데 그 이후 꼬리 구간에서 잔차가 한쪽으로 계속 치우치는 패턴이 나타남
(그림: `docs/03_results/w3_1rc_residual.png`, 아직 생성 전)

**고려한 대안**:
- **A. 1RC 유지, 잔차 무시**: 연산량이 가장 작고 3개 파라미터(R0,R1,C1)만
  추적하면 됨. 하지만 SOP 계산 시 10초 후 전압 예측이 실제보다 낙관적으로
  나올 가능성 — 느린 확산 성분을 놓치기 때문.
- **B. 2RC**: 빠른 시상수(전하이동, ~1-2초)와 느린 시상수(확산, ~수십 초)를
  분리. 잔차가 백색에 가까워짐(예상).
- **C. 3RC**: 이론적으로 더 정밀. 하지만 시상수가 서로 겹치면 피팅이
  불안정해질 위험이 있음(라플라스 극점이 가까우면 데이터로 구분 불가 — 상세:
  `docs/02_theory/W0_foundations.md` Q2 참고).

**선택**: B (2RC)

**근거**: SOP는 10초 지평의 전압 예측에 직결되고(`docs/02_theory/W7_sop.md`),
느린 시상수를 놓치면 SOP를 과대평가하게 되어 안전 마진을 잘못 잡을 수 있음.
3RC는 아직 시도하지 않았으나, 예비 검토 결과 τ2, τ3 후보가 10초 이내로
가까워 식별 불안정이 우려되어 2RC로 먼저 진행하고 필요시 재검토.

**폐기한 실험**: 없음 (3RC는 아직 미시도, 향후 `experiments/3rc_attempt`
브랜치에서 검증 예정)

## D-002: 이산화 방법을 ZOH로 결정

**날짜**: 2026-XX-XX
**맥락**: 초기 구현에서 전진 오일러로 이산화했을 때 Δt=1s, τ1≈1.2s인 상태에서
필터가 간헐적으로 발산하는 현상 관찰 (`docs/00_learning_log.md` W0 참고)

**고려한 대안**:
- **A. 전진 오일러 유지 + Δt를 줄임**: 구현이 단순하지만 Δt를 줄이면
  연산 부담이 커지고, 실제 BMS 샘플링 주기(보통 100ms~1s) 제약과 충돌
- **B. ZOH(영차 유지) 이산화**: RC 회로는 해석해가 존재하므로 근사 오차 없이
  정확히 이산화 가능. 연산량은 지수함수 계산 한 번 추가되는 정도.

**선택**: B (ZOH)

**근거**: RC 시스템은 선형이라 ZOH의 해석해를 그대로 쓸 수 있어 근사 오차가
없고, 계산 비용 증가가 무시할 만한 수준. 자세한 이산화 안정성 조건(Δt < 2τ)은
`docs/02_theory/W0_foundations.md` Q8 참고.

**폐기한 실험**: 전진 오일러 버전은 `src/models/` 내 비교 목적으로 유지
(운영 코드는 ZOH만 사용)

  중요합니다.

  이전 항목을 참조 (`D-00X를 대체함` 형식)
