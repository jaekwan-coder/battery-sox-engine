# 학습 로그

주차별로 무엇을 배우고, 무엇에서 막혔고, 어떻게 풀었는지 기록합니다.
**막힌 지점과 실패를 의도적으로 남깁니다.** 성공만 적힌 로그는 증거로서 힘이 없습니다.

각 항목은 아래 다섯 칸을 채우는 걸 원칙으로 합니다.

## W0 — 기초 정비 (2026-XX-XX ~ 2026-XX-XX)

### 목표
회로·제어·확률 이론 중 SOX 구현에 실제로 쓰이는 최소 세트를 복원한다.
자가진단 8문항(RC 지수응답, 라플라스/극점, 상태공간, 가관측성, 공분산,
가우시안 곱셈, 최소자승법, 이산화)에 스스로 답할 수 있는 상태를 목표로 함.

### 실제로 한 것
- 8문항 자가진단 실시 → 8개 중 6개 막힘 확인
- RC 병렬 임피던스를 ω 0→∞로 손계산 후 나이퀴스트 평면에 직접 플롯
  → 반원이 나오는 것을 확인 (`notebooks/00_rc_nyquist.ipynb`)
- 전진 오일러 vs ZOH 이산화 비교, Δt/τ 비율을 바꿔가며 안정성 관찰
  (`notebooks/01_discretization.ipynb`)

### 막힌 지점
- "가관측성"이라는 말을 처음엔 그냥 "센서가 있냐 없냐"로 오해함.
  OCV 곡선 기울기와의 연결을 못 잡고 있었음.
- 가우시안을 "곱한다"는 게 왜 "가중합"이 아닌지 직관이 안 잡힘.
  확률의 AND/OR 구분을 다시 봐야 했음.

### 어떻게 풀었나
- 가관측성: "출력(전압) = 상태(SOC)의 함수인데, 그 함수의 기울기가 0이면
  상태가 변해도 출력에 안 나타난다"로 재정의하고 나서야 LFP 평탄 구간
  문제와 연결됨.
- 가우시안 곱: 주사위 두 개 동시에 6 나올 확률 예제로 AND=곱셈이라는
  걸 먼저 확인한 뒤, "모델 예측도 맞고 측정도 맞다고 믿는다"는 우리
  상황이 AND라는 걸 납득함.

### 다음 액션
- W1 진입 전 EIS 나이퀴스트 ↔ RC 회로 대응을 한 번 더 손으로 확인
- OCV(SOC) 곡선의 실제 데이터(LG HG2)를 아직 안 봤음 → W1에서 확인

## W1-2 — 셀→회로 번역 (2026-XX-XX ~ 2026-XX-XX)

### 목표
전기화학 최소 세트(산화환원, 화학포텐셜, OCV-SOC 곡선의 소재별 형태,
히스테리시스, 3단계 율속)를 이해하고 M1.6에서 2RC ECM을 상태공간으로
조립한다. 이어서 EIS·나이퀴스트 선도를 유도해 시간영역(M1)과
주파수영역(M2)이 같은 물리를 어떻게 다르게 보여주는지 확인한다.

### 실제로 한 것
- M1.0~M1.6: 전압의 정의부터 화학포텐셜, OCV-SOC 곡선(고용체 vs
  상전이), 히스테리시스, R0/RC1/RC2의 물리적 기원(3단계 율속)까지
  순서대로 정리 (`docs/02_theory/W1_electrochemistry_ecm.md`)
- M2.0~M2.7: 교류·임피던스 기초부터 RC 병렬의 반원 유도(W0 Q1/Q2
  재활용), RC 여러 개 직렬연결 시 반원이 여러 개로 분리되는 이유를
  숫자로 직접 계산, Randles 회로의 위치(방향 A/B 구분), Warburg
  임피던스(45도선), 나이퀴스트 vs 보데 선도, EIS의 실무 활용까지 정리
  (`docs/02_theory/W2_eis.md`)

### 막힌 지점
- M2.2에서 "RC 여러 개가 직렬로 연결되면 왜 반원이 여러 개인가"를
  처음엔 "그냥 반원이 여러 개 생긴다" 정도로만 이해하고 넘어가려 했음.
  실제로 왜 그런지 수식으로 확인이 안 된 상태였음.
- Randles 회로가 왜 갑자기 튀어나온 개념처럼 느껴졌음. "나이퀴스트
  선도를 회로로 정리한다"는 말의 논리 방향(회로→곡선 vs 곡선→회로)이
  헷갈렸음.
- "노화"와 "열화"를 같은 말로 무심코 섞어 썼는데, 정확히 같은 뜻인지
  헷갈림.

### 어떻게 풀었나
- 반원 분리: τ1=2초, τ2=100초인 두 RC 블록을 실제 숫자(ω=10, 0.5,
  0.01 rad/s)로 각각 계산해보니, τ가 충분히 다르면 "블록1이 반원을
  다 그리고 끝난 뒤에야 블록2가 시작"하는 게 직접 확인됨. τ가
  가까우면(2초 vs 3초) 이게 안 되고 뭉개진다는 것도 확인 — W0 Q2의
  "라플라스 극점이 가까우면 구분 안 됨"과 같은 문제였음.
- Randles 회로: "방향 A(회로→곡선, 우리가 M2.1에서 한 것)"와
  "방향 B(곡선→회로, 실제 실험에서 하는 것)"를 구분하고 나니, Randles
  회로가 "방향 B를 위한 표준 템플릿"이라는 게 납득됨. 새 이론이
  아니라 M1.6에서 이미 만든 회로에 이름표가 붙은 것.
- 노화/열화: 노화=현상(결과), 열화=메커니즘(원인)이라는 위계 관계로
  정리. "노화됐다 → 어느 열화 메커니즘 때문인가?"가 EIS 진단의 정확한
  구조였음.

  전환할 것

## W3 — 파라미터 식별 (2026-XX-XX ~ 2026-XX-XX)

### 목표
W1-2에서 만든 ECM 구조에 들어갈 실제 숫자(OCV 곡선, R0/R1/C1)를
공개 실험 데이터에서 뽑아내는 방법을 이해한다. 아울러 노화로 파라미터가
변할 때 이를 실시간으로 갱신하는 RLS까지 다룬다.

### 실제로 한 것
- M3.0~M3.5 이론 정리 (`docs/02_theory/W3_parameter_identification.md`)
- LG HG2 / Samsung 30T 공개 데이터셋의 실제 구조를 Mendeley 원문에서
  확인하고 `data/README.md`에 정리
- 시험 블록별 목적(HPPC / C20 / 드라이브사이클)과 커리큘럼 대응 매핑

### 막힌 지점
- "SOC를 추정하는 게 목적인데, HPPC 실험은 어떻게 시작부터 SOC를
  90%로 정확히 맞춘다는 것인가?" — 순환논리처럼 보여서 한참 걸렸음.
- 공개 데이터셋이 셀 제조사(LG)가 직접 낸 것인지, 제3자가 낸 것인지
  구분하지 못하고 있었음.
- **가장 중요한 발견**: 초반에 "LG HG2 데이터셋의 HPPC를 쓰자"고
  계획했는데, Mendeley 공개 문서를 실제로 확인해보니 **LG HG2에는
  HPPC가 명시적으로 나열되어 있지 않았음.** 드라이브 사이클이 중심.
  확인 없이 가정하고 계획을 세웠던 것.

### 어떻게 풀었나
- SOC 참값 문제: 실험실과 차량은 완전히 다른 조건이라는 걸 깨달음.
  완충=CC-CV 종료 시점으로 **정의**하고, 총 용량 Q를 직접 재고,
  정밀 장비(풀스케일 0.1% 정확도)로 짧은 시간만 적산하면 쿨롱카운팅이
  사실상 정확함. 차량의 문제(값싼 센서 + 수년 누적)가 여기선 안 생김.
  → 순환이 아니라 위계 구조(실험실 참값 → 모델 → 차량이 모델 참조).
- 데이터 출처: "LG"는 셀 모델명일 뿐이고, 시험·공개 주체는 McMaster
  University 연구실. 제조사 내부 데이터는 영업비밀이라 공개 안 됨.
- HPPC 문제: 같은 실험실(Kollmeyer)의 **Samsung INR21700 30T**
  데이터셋에는 HPPC 프로토콜이 명확히 문서화되어 있음을 확인.
  → 두 데이터셋을 함께 쓰는 전략으로 전환 (Samsung 30T로 파라미터
  식별, LG HG2 드라이브 사이클로 필터 검증).

### 배운 것 (방법론)
**데이터셋을 계획에 넣기 전에 반드시 공식 문서를 직접 확인할 것.**
이름만 보고 "당연히 있겠지" 하고 가정하면 나중에 계획 전체를 다시
짜야 한다. 이번엔 코드 작성 전에 발견해서 손실이 적었음.

  정확히 어느 개념에서 어떤 오해를 했는지)
- 그림/코드 결과를 참조할 때는 상대경로로 링크
- 이 문서는 시간순 기록이고, 재사용 가능한 개념 설명은 `02_theory/`로 옮길 것
