# 데이터

## 데이터를 git에 올리지 않는 이유

용량이 크고(수백 MB~GB) 원본이 공개되어 재다운로드가 가능하므로
저장소에 포함하지 않는다(`.gitignore` 처리). 다만 `data/processed/`에
생성한 파라미터 룩업테이블처럼 **용량이 작고 재현에 시간이 오래 걸리는**
결과물은 예외적으로 커밋할 수 있다 — 이 경우 `.gitignore`에서 해당
파일만 명시적으로 제외 처리(`!data/processed/params_lookup.csv`)한다.

---

## 공개 데이터셋의 성격 — 먼저 알아둘 것

"LG 18650HG2"는 **셀의 모델명**이며 LG가 제조한 하드웨어를 가리킨다.
실제로 이 셀을 시험하고 데이터를 공개한 주체는 **McMaster University
(캐나다)의 연구실(Dr. Phillip Kollmeyer 등)**이다.

셀 제조사의 내부 데이터는 영업비밀이라 공개되지 않는다. 접근 가능한
공개 배터리 데이터셋은 대부분 **대학이 상용 셀을 구매해 독립적으로
표준시험을 수행한** 형태다.

→ 우리가 뽑는 파라미터는 "LG의 공식 스펙값"이 아니라 "McMaster
연구실이 자신들의 장비로 측정한 값"이다. 학습·포트폴리오 목적으로는
충분히 신뢰할 만하지만, 이 구분은 알고 있어야 한다.

## 1차 데이터셋: LG 18650HG2 (McMaster University)

### 두 개의 다른 버전이 있다 — 헷갈리지 말 것

| 구분 | Mendeley DOI | 성격 |
|---|---|---|
| **원본 데이터** | `b5mj79w5w9` | 시험 원자료. 신경망·칼만필터 SOC 알고리즘 시험이나 배터리 모델 개발용 |
| **가공 데이터 + 예제** | `cp3473x7xv` (v3) | FNN(심층 순방향 신경망) 예제 스크립트용으로 이미 전처리된 형태 |

- 원본: https://data.mendeley.com/datasets/b5mj79w5w9/2
- 가공본: https://data.mendeley.com/datasets/cp3473x7xv/3

**우리 목적(ECM 파라미터 식별)에는 원본(`b5mj79w5w9`)이 더 적합하다.**

가공본(`cp3473x7xv`)의 구조는 각 파일이 5개 예측변수(전압, 전류, 온도,
평균전압, 평균전류)의 시계열 X와 1개 목표값(SOC)의 시계열 Y를 담고
있으며, 각 파일이 서로 다른 주위 온도에 해당한다. 여기서 "평균전압,
평균전류"는 원래 측정값이 아니라 **연구팀이 신경망 학습용으로 만든 파생
변수**이고, Y(SOC)는 실험실 정밀장비의 쿨롱카운팅으로 계산한 **정답
라벨**이다.

### 시험 장비와 조건 (공개 문서 명시 사항)

- 새 3Ah LG HG2 셀 **1개** (NMC 화학)
- 8입방피트 항온챔버
- 75A / 5V Digatron Firing Circuits 유니버설 배터리 테스터 채널
- 전압·전류 정확도: **풀스케일 대비 0.1%**

**이 0.1%가 "실험실에서는 왜 SOC를 참값으로 취급할 수 있는가"의
근거다** (`docs/02_theory/W3_parameter_identification.md` M3.0 참고).

**주의**: 셀이 한 개다. 여러 셀의 편차(팩 레벨 문제, W7)를 볼 수 있는
데이터가 아니다.

### 포함된 시험 내용

문서화된 바로는 **드라이브 사이클이 중심**이다.

- 주위 온도 6개: -20°C ~ 40°C
- 표준 드라이브 사이클 4개: UDDS, LA92, HWFET, US06
- 추가 인공 사이클 8개: Mixed 1~8 (위 네 개를 무작위로 섞은 것)
- 각 시험 전 완충, 해당 온도의 1C 방전용량 95%까지 방전

| 사이클 | 성격 |
|---|---|
| UDDS | 잦은 정차·출발이 있는 저주파 도심 주행 |
| HWFET | 정상상태 고속도로 주행 |
| LA92 | 중속 가변 조건의 혼합 주행 |
| US06 | 고빈도 급가감속의 극한 출력 요구 |

### ⚠️ 중요: HPPC에 대한 정정

**공개 설명문에 HPPC 시험이 명시적으로 나열되어 있지 않다.** 이
데이터셋의 중심은 드라이브 사이클이다. HPPC 기반 파라미터 식별
(W3 M3.3)을 하려면 아래 대안을 검토해야 한다.

## HPPC 대안: Samsung INR21700 30T (같은 실험실, 같은 장비)

- https://data.mendeley.com/datasets/9xyvy2njj3/1
- 동일하게 Kollmeyer 팀(McMaster)이 같은 Digatron 장비로 시험

**프로토콜이 명시적으로 문서화되어 있다**:

1. **4펄스 방전 HPPC 시험** (1, 2, 6, 12C 방전 및 0.5, 1, 2, 4C 충전,
   저온에서는 값 축소)을 100, 95, 90, 80, 70, ..., 20, 15, 10, 5, 2.5%
   SOC에서 수행 → `..._HPPC.mat`
2. **C/20 방전 및 충전 시험** → `..._C20DisCh.mat`
3. 0.5C / 2C / 1C(2회) 방전 시험 → `..._Dis_0p5C.mat`, `..._Dis_2C.mat`,
   `..._Cap_1C.mat`
4. 드라이브 사이클 4개: UDDS → HWFET → LA92 → US06
5. Mixed 1~8 (위 네 개의 무작위 조합)
6. 위 시험 전체를 40, 25, 10, 0, -10, -20°C 순서로 반복.
   10°C 미만에서는 **셀 조기 노화 방지를 위해 회생 전류 한계를 낮춤**

### 각 블록의 목적 — 우리 커리큘럼과의 대응

| 블록 | 목적 | 쓰임 |
|---|---|---|
| HPPC | 각 SOC·온도에서 저항·동특성 측정 | **M3.3: R0, R1, C1 추출** |
| C/20 충방전 | 저율이라 IR 손실 무시 가능 | **M3.2: OCV(SOC) 곡선** |
| 0.5C/1C/2C 방전 | C-rate별 가용 용량 | 용량 Q 확정, 비선형성 확인 |
| 드라이브 사이클 | 실주행 패턴 재현 | **W4-5: 필터 검증** (파라미터 추출용 아님) |
| Mixed 1-8 | 표준 사이클 무작위 조합 | 학습/검증 데이터 분리 |

**설계상 눈여겨볼 점**: 1C 방전 시험이 UDDS 전과 Mix3 전 **두 번**
배치되어 있다. 긴 시험 도중 셀이 열화되지 않았는지 중간 점검하기
위해서다. 앞뒤 용량이 크게 다르면 시험 중 셀이 변했다는 뜻이고,
데이터 일관성을 의심해야 한다.

### 권장 전략

**두 데이터셋을 함께 쓴다.**
- Samsung 30T의 HPPC로 파라미터 식별 기법 습득 (M3.3)
- LG HG2의 드라이브 사이클로 필터 검증 (W4-5)
- 포트폴리오 관점에서도 "두 셀 화학에 같은 방법론을 적용"이 더 강하다

## EIS 데이터가 필요한 경우

위 두 데이터셋에는 EIS가 없다. 이유는 세 가지:
① 장비가 다름(사이클러 vs 임피던스 분석기/FRA), ② 목적이 다름(SOC
알고리즘 검증 vs 임피던스 특성화), ③ EIS는 작은 신호 조건이라 실차
주행과 거리가 있음.

**대안**: Helmholtz Institute Ulm / DLR / SINTEF 공동 공개
INR18650-MJ1(LG CHEM 제조) 셀의 GITT+EIS 원자료.
- https://zenodo.org/records/15536942
- NMC 작용전극 / 흑연·실리콘옥사이드 상대전극 / 리튬금속 기준전극의
  3전극 코인셀 구성
- NMC 소재의 리튬 확산계수 특성화를 위해 의도된 데이터
- W2의 나이퀴스트 해석을 실제로 해볼 수 있는 재료
